# Правила проверок

Проверяем то, что изменили, и то, что правка реально могла задеть. Без полных прогонов «на всякий случай» и без повторов одного и того же. Как запускать инструменты — [docs/CONTROL.md](docs/CONTROL.md).

## Общие правила

- Время проверок не больше времени разработки.
- По умолчанию — **быстрая** проверка: целевой тест изменённой системы и `tools/control/check.gd` на одном мире (одна генерация: снимки и FPS в ней же).
- **Глубокая** (`check.gd --deep`, несколько сидов, полные замеры) — только для тяжёлых и спорных мест: падение FPS больше шума, странный мир на одном сиде, правка генерации, которая меняет многие миры. Цель — докопаться до причины, а не подтвердить «всё хорошо».
- Отладка и подбор чисел — на 1–2 снимках (`--views road --fps off`, свой `--world`). Полный набор видов и замер — один раз в конце.
- «Было» не пересъёмывать: база — прогон прошлой версии в `tools/control/runs`, повтор того же коммита берётся из кэша. Если базы нет — один прогон до правок.
- Тест не повторять, если с прошлого запуска код, который он проверяет, не менялся. FPS повторить один раз, только если разница больше шума (15 %).
- Перед `--script` запусками в сборке .NET — `dotnet build`; новый `class_name` — сначала `godot --headless --import`.
- В отчёте пользователю коротко: что проверено и что нет.

## Что брать для какого изменения

| Изменение | Проверка |
|---|---|
| Генерация мира (рельеф, реки, дороги, поселения, растительность) | `tools/selftest.gd` (C# и `-- --gdscript`), тест своей стадии, `check.gd --fps off` на мире, где видно изменение |
| Рельеф | + дороги (`road_bed_test`, `road_refinement_test`) и велосипед (`feel_test`) — их задевает высота |
| Дороги, мосты, туннели | `route_test`, `road_bed_test` / `road_refinement_test`, `check.gd --world Ущелье --views road --fps off` |
| Реки, озёра, вода | `hydrology_test` / `river_geometry_test` / `water_surface_test`, `check.gd --views valley` |
| Местность за краем стартовой области, хеш по месту | `territory_test` (+ selftest, если менялась стартовая область), 1–2 снимка края |
| Растительность, лес | `vegetation_test` / `forest_test` / `understory_test`, `check.gd` с FPS |
| Графика, шейдеры, свет, небо | `check.gd` (снимки + FPS), для света `--hours 7.5,19.1` |
| Тяжёлые системы (подгрузка, сетки, большие циклы) | `check.gd` с FPS; глубокая — если FPS или загрузка упали больше шума |
| Велосипед, движение, камера | `feel_test`, тесты велосипеда (`bike_physics_test`, `bike_handling_test`, `bike_crash_test`), без selftest и FPS |
| Столкновения | `forest_collision_test`, `feel_test` |
| Жизненный цикл мира, меню, память | `lifecycle_test` |
| Частота кадров и физика | `fps_test` |
| Интерфейс, настройки, звук | `settings_test` / `sound_check` или 1 снимок, без генерации нескольких миров |
| Только документы и правила | ничего не запускать |
