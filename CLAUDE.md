# Правила проверок

## Главное правило (читать первым)

**По умолчанию запускается только одна проверка — единая `tools/control/check.gd` на одном мире.** Перед ней и после неё ничего не запускать: ни отдельных тестов, ни `selftest`, ни сверки с эталоном на нескольких мирах, ни замеров «до» и «после», ни `bench.gd`, ни повторов.

- Отдельный тест — только если правка **прямо** затрагивает его систему и `check.gd` её **не покрывает** (снимки, FPS, время загрузки, сводка мира и хеши в `stats_<мир>.json` покрывают большую часть). Тогда этот тест — **один**, **один раз**. Не два «для надёжности».
- «Было» — прогон прошлой версии в `tools/control/runs`, его не пересъёмывать.
- Совпадение мира с прошлой версией проверяется по хешам из сводки `check.gd`, а не отдельным `selftest` или эталоном.
- Если кажется, что нужна ещё проверка, — не запускать её, а написать в отчёте, что не проверено. Пользователь решит сам.
- Только документы и правила — ничего не запускать.

Как запускать инструменты — [docs/CONTROL.md](docs/CONTROL.md).

## Общие правила

- Время проверок не больше времени разработки; на втором ПК мир 256 грузится больше минуты.
- Отладка и подбор чисел — на 1–2 снимках (`--views road --fps off`, свой `--world`). Полный набор видов и замер — один раз в конце, это и есть единая проверка.
- **Глубокая** (`check.gd --deep`, несколько сидов) — только по просьбе пользователя или когда единая показала падение FPS/загрузки больше шума (15 %) и нужна причина.
- FPS повторить один раз, только если разница больше шума. Короткие выборки (3 с) шумные: повтор — `--look 10 --road 10`.
- Процессы Godot с генерацией не запускать параллельно: они сбивают время и FPS.
- Перед `--script` запусками в сборке .NET — `dotnet build`; новый `class_name` — сначала `godot --headless --import`.
- В отчёте пользователю коротко: что проверено и что нет.

## Единственный допустимый отдельный тест

Только когда `check.gd` не видит изменённую систему. Не больше одного на изменение.

| Изменение | Отдельный тест (если нужен) |
|---|---|
| Генерация мира, рельеф, реки, дороги, мосты, туннели | не нужен: хеши мира, снимки `road`/`valley` в `check.gd` (`--world Ущелье` для мостов) |
| Местность за краем стартовой области | `territory_test` |
| Велосипед, движение, камера | `feel_test` (вместо `check.gd`, без FPS) |
| Столкновения | `forest_collision_test` |
| Жизненный цикл мира, меню, память | `lifecycle_test -- --size 256 --worlds 3` |
| Графика, шейдеры, свет, небо, растительность, тяжёлые системы | не нужен: `check.gd` с FPS (для света `--hours 7.5,19.1`) |
| Интерфейс, настройки, звук | `settings_test` / `sound_check` или 1 снимок вместо `check.gd` |
| Только документы и правила | ничего не запускать |
