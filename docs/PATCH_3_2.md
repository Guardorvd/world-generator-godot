# Проверка патча 3.2

Сравнение с 3.1 (`3383088`) на прежних 12 сидах размером 512 × 512. Ветка та же:
`codex/patch-3.1-mountains`.

## Изменения

- `UPLAND_SHIFT`: 0,08 → 0,24 — больше массивов становятся холмистыми возвышенностями.
- `UPLAND_AMP`: 0,4 → 0,3 — у возвышенностей ниже гребни и шире склоны.
- Холмистый характер ослабляет остроту и асимметрию склонов; `SHARP_SHIFT`: 0,2 → 0,28.
- Мягкий предел вершин: `PEAK_KNEE` 0,4 → 0,36, `PEAK_SOFT` 0,3 → 0,25.
- Мелкий шум холмов внутри массивов ослаблен пропорционально горной маске: широкие склоны
  меньше дробятся на бугры. На равнинах с нулевой маской этот слой прежний.

Правки в существующих формулах `StageRelief` и `FastGrid`. Дополнительных шумов, проходов по карте,
массивов и расчётов в игровом кадре нет. Карта и её продолжение используют ту же функцию высоты.

## Распределение рельефа

Среднее по 12 мирам, без взвешивания площадью. В расчёт входят сухие внутренние клетки карты.
«Холмистая местность» для сравнения — клетки высотой 20–80 м со склоном меньше 25°;
это численный ориентир, а не отдельный биом.

| Показатель | 3.1 | 3.2 |
|---|---:|---:|
| Суша выше 150 м | 0,835 % | 0,443 % |
| Суша выше 80 м без русел | 11,79 % | 10,41 % |
| Холмистая местность 20–80 м, склон <25° | 17,80 % | 18,90 % |
| Склоны круче 35° на суше | 29,35 % | 26,00 % |
| Склоны круче 45° среди гор | 44,63 % | 34,55 % |
| Средняя максимальная высота мира | 208,9 м | 188,1 м |

Высоких участков примерно на 47 % меньше. Доля пологой холмистой местности выросла в 11 из 12 миров.
Результат зависит от сида: отдельные высокие и скалистые массивы сохраняются.

## Проверки

- `dotnet build --no-restore`: без ошибок и предупреждений.
- `tools/geography_test.gd`: 12 сидов, конечные высоты, сток, сухие поселения и дома,
  связь поселений, непрерывность гребня, стыки и точное совпадение высот C#/GDScript.
- Полные результаты `tools/selftest.gd -- --print` совпали с `-- --print --gdscript`;
  обновлённый эталон проверен обычной самопроверкой.
- `tools/feel_test.gd`: проходы пешком и на велосипеде, мосты, туннели, вода и линии путей.
  Проверка уточнена: тропа ниже настила больше чем на высоту шага не считается проходящей через
  перила; для координат точек тела float32 учитывается погрешность 1 мм.
- Четыре контрольных мира сняты в 3D: вершины, долины, дороги, поселения, появление и карта.

Загрузка среднего «Север-1234» через `tools/bench.gd`: 7,82 с → 8,48 с в одиночных замерах
на той же машине. Замеры шли с фоновыми проверками; различие около 8 % не позволяет отделить
влияние нового расположения путей от разброса времени. FPS в этом патче отдельно не измерялся.

Сырые сводки и снимки лежат в игнорируемых папках `tools/control/runs/3.2-before` и `3.2-after`.
Исходные снимки взяты из последнего контрольного прогона 3.1.
