# 8.0 — быстрые проверки

Игра и миры не менялись. Изменились проверки разработки.

- **Единая проверка** `tools/control/check.gd`. Мир генерируется один раз, и в нём же снимаются виды и меряется FPS; потом прогон сам сравнивается с прошлой версией. Раньше снимки (`shots.gd`) и замер (`perf.gd`) генерировали мир каждый заново, а загрузка мира 512 — основная часть времени (40–60 с).
- **Две ступени.** Быстрая (по умолчанию): один мир, выбранные виды (`--views`), FPS по желанию (`--fps off`). Глубокая (`--deep`): все миры и размеры, по процессу на мир, только для тяжёлых и спорных мест.
- **Кэш базы.** «Было» — это прогон прошлой версии в `tools/control/runs`; отдельно его не снимают. Тот же коммит без правок второй раз не генерируется. `compare.gd` сравнивает только то, что снято в новом прогоне.
- Снимки всегда в полдень (`--hours` добавляет другие часы), а не в час из настроек игрока.
- **Правила для агентов** — `CLAUDE.md` в корне: какую проверку брать для какого изменения, когда быстрая, когда глубокая, лимит времени проверок.

Проверки: быстрая проверка одного мира (Ущелье@512, виды без FPS) отработала, около минуты, из них загрузка мира 43 с. Глубокая проверка проверена не полностью: в первом запуске (с окном у главного процесса) прошли два мира из шести; теперь её нужно запускать с `--headless`, повторно не запускалась.
