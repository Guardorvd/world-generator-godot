## Что убрано и исправлено

| Находка | Изменение | Игровой смысл |
| --- | --- | --- |
| Повторный запрос обновлял число приоритета, но не позицию чанка в очереди. | Пересортировка выполняется и при обновлении существующего запроса; дубликат не создаётся. | После смены направления ближайший запрошенный чанк действительно читается раньше удалившегося. |
| Прогрев сортировал все ключи всех слоёв по первой точке, хотя возвращается только после подготовки всех нужных блоков. | Оставлен линейный отбор по радиусу; просмотр точек прекращается при первом попадании. | Нет сортировки дальних ненужных чанков и лишних сравнений расстояний. Пустой список точек корректно ничего не делает. |
| При тесной памяти чтение отсутствующей земли могло вытеснить кэшированную воду, которую тот же прогрев собирался запросить позже. | Сначала закрепляются все нужные попадания в RAM во всех слоях, затем читаются отсутствующие блоки. | Нужные данные не теряются из кэша из-за порядка обхода слоёв. Стенд подтверждает одно чтение отсутствующей земли с сохранением воды из RAM. |
| Код закрепления блока и учёта его памяти повторялся в прогреве и обработке фонового результата. | Общая короткая функция `_pin`. | Один путь учёта закреплённых данных. |
| Гарантированный кадр для области зависел от наличия `vegetation_budgeted`, хотя растительность не участвует в её публикации. | Убрана зависимость от обработчика растительности. | Непрерывная очередь внешнего рельефа не блокирует области при отключённой растительности; готовая область получает приоритет. |
| Общий CPU-бюджет при запросе размера владельца обходил все записи; пакетное вытеснение многократно обходило их или создавало полный массив ключей для каждого удаления. | Сумма владельца поддерживается при вставке и удалении, её чтение O(1). При вытеснении используется один проход по снимку ключей с прежним порядком LRU. | Уменьшена служебная работа общего кэша, особенно при освобождении большого объёма памяти. Лимиты и порядок вытеснения сохраняются. |
| Загрузчик сохранял неиспользуемый `_retried`, а вызывающие передавали лишний `false` перед стартовой позицией. | Параметр удалён, все три явных вызова обновлены. | Простой контракт загрузки без оставшегося переключателя несуществующего пути повторной генерации. |
