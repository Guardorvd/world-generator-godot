# 13.7 — ревизия 13.0–13.6

Мир, стартовая генерация, сохранения и игра не меняются: подготовка соседних областей
по-прежнему не подключена к игровой сцене.

## Исправлено

- `region_water_surface.gd`: в 13.3 вместе с заглушками на концах русла пропали и скругления
  внутренних вершин. Ось реки идёт по клеткам с поворотами под прямым углом, и на каждом
  повороте внешний угол ленты оставался без берега, а у широкой реки (полуширина больше
  1,4 клетки) — сухим пятном посреди воды. Теперь пропускаются только начало и конец русла
  (стык с соседом, слияние, море), внутренние вершины скругляются.
- `region_rivers.gd`: учёт поперечного профиля из 13.5 работал только в поиске через впадины.
  Основной спуск по оси принимался без проверки ширины, и река вдоль склона отклонялась
  поверхностью по `earthwork_limit`. Теперь каждая клетка оси проверяется тем же
  `section_limits`; при нарушении используется поиск с профилем, а если и он не находит
  выхода, остаётся прежний маршрут с точной причиной отказа поверхности.

## Проверено ревизией без изменений

Стык выходов и входов соседей, слияния и сумма стока, куча `MinHeap.pop`, отбор
поселений по мировым окнам (дома не выходят за свою область: `LAYOUT_R` 6,8 < `MARGIN` 8),
откат непригодных дорог и мостов, перевод координат дорог и мостов в мировые.
