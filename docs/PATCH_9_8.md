# 9.8 — весь большой мир открыт и заселён

Контроль: Север-1234, план 768 × 768, Ryzen 7 2700, GTX 1650 SUPER.

## Как было на деле

- План 768 × 768 и раньше генерировался целиком (реки, дороги, лес, места), но со старта открывалось только
  окно 256 × 256 вокруг дома (`WorldGenerator.START_SIZE`). Остальное открывалось при подъезде к краю, места
  за окном не попадали в список на карте.
- Поселения ставились на весь план (на контрольном мире 11 кандидатов), но **оставались только 2**, оба у старта.
  Сеть дорог росла от одного поселения; остальные отделяла средняя река (глубина около 1,3 м), над которой мост
  не встаёт (неровные берега у въезда). Каждая неудачная попытка съедала весь запас поиска A* поселения,
  после чего оно выбрасывалось как «неподтверждённое». Поэтому на большой карте и не было поселений.

## Что изменено

1. **Весь план открыт со старта**: `START_SIZE = PLAN_SIZE`. Окно меньше плана осталось только для инструментов
   (`--size`), для них соседние земли по-прежнему открываются по ходу.
2. **Несколько сетей дорог** (`StageTrails._settlement_trails`). Когда текущая сеть больше не растёт, следующее
   по значимости поселение начинает свою; оставшиеся получают ещё один запас A* (`w.N`, один раз за генерацию).
   Остаются поселения, у которых есть дорога хотя бы к одному соседу; первое, как и раньше, — всегда.
3. **Тропа между сетями** (`_second_ways`). Если у соседних поселений нет пути по сети, ищется тропа по суше:
   вброд через узкую реку, по мосту или в обход. На контрольном мире она связала обе сети, все поселения
   снова связаны (`connected: true`).
4. **Дома и мосты собираются по квадратам 256 м** (`MeshBatch`), у каждого квадрата дальность 1400 м. Раньше
   все дома мира шли одним мешем, который камера никогда не отсекала: с поселениями по всему плану FPS падал
   вдвое (222 → 109), теперь рисуется только ближнее.

Мир Север-1234 изменился: поселений 2 → 8 (по всей площади), дорог 1 → 6, троп 1 → 6, мостов 1 → 12.
Хутора и одинокие дома тоже прибавились немного (они ставятся у дорог).

## Замеры (`check.gd`, окно 768)

| | 9.7 (окно 256) | 9.8 |
|---|---:|---:|
| Загрузка | 57,6 с | 67,0 с (70,6 с в первом прогоне) |
| Генерация | 46,1 с | 48,1 с |
| Полотно дорог (`finish_paths`) | 2,9 с | 8,3 с |
| Постройки поселений в сцене | 0,45 с | 2,6 с |
| FPS осмотр / 1 % худших | 222 / 157 | 241 / 204 |
| FPS дорога / 1 % худших | 219 / 156 | 226 / 186 |
| Память после загрузки | 1404 МБ | 1635 МБ |

Загрузка выросла примерно на 10 с (+16 %): это цена самих новых поселений и дорог (полотно дорог, планировка,
постройки), а не открытого окна. Окно на время загрузки не влияет. FPS на месте появления другой: дом теперь
в другом поселении.

## Проверки

- `check.gd --size 768 --views spawn,road,settlement,map --fps on`: всё снято. FPS упал вдвое, причина найдена
  (общий меш домов) и исправлена; повтор FPS один раз (`--views spawn,settlement`) — 241/226.
- Отладка — один скрипт-генерация мира без сцены (число поселений, связность, время дорог).

Не запускались (мир намеренно изменился, их эталоны нужно обновить отдельно): `selftest` (эталонные хеши
мира устарели), `route_test`, `bridge_test` (поправлен под новый `MeshBatch`, не запускался),
`settlement_network_test`, `world_plan_test`, `continuation_test` (проверяют окно 256 и открытие соседей),
`lifecycle_test`. Глазами в игре не проверены тропа между сетями и дальность 1400 м у домов.
