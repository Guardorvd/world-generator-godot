# Типы путешествий в главном меню

Главное меню и каталог «Все типы» читают один список `WorldTemplate.menu_types()` из
`scripts/world/world_template.gd`. Порядок задаётся `_CATALOG`. У готовой записи в каталоге
хранятся путь к конфигурации, короткое `description` и путь `artwork` к примеру ландшафта.
Название, `id` и `available` берутся из `WorldTypeConfig` соответствующего `.tres`.

Чтобы добавить готовый тип, создайте его конфигурацию в `resources/world_types`, добавьте
одну запись в `_CATALOG` с таким же стабильным `id` и подготовьте генерацию, кэш и сохранения
по `WORLD_TEMPLATES.md`. Меню само строит кнопки и каталог из списка. Кадр используйте
небольшой, например 640×360, и сохраняйте в `resources/menu`: он демонстрирует тип, а не
конкретное зерно. Отсутствующее изображение не мешает открытию меню.

Заглушка не имеет пути к `.tres` и должна оставаться `available = false`. Она показывается
в разделе «В разработке», но не передаётся в нормализацию id, кэш или запуск мира.
Идентификатор конфигурации готового типа обязан совпадать с id записи каталога: иначе
пункт недоступен. Данные истории по типам и идентификаторы сохранений не меняются.

`world_carousel.gd` показывает текущую карточку, соседние типы, пример и выбранный мир;
просмотр будущей карточки не меняет активный тип и временно блокирует запуск.
Карты конкретных
зёрен остаются в существующей системе предпросмотра. `world_type_catalog.gd` используется
для выбора типа и на главной, и в библиотеке миров. Черновик нового мира и переходы к
загрузке находятся в `main.gd`; оформление использует общую тему `resources/ui_theme.tres`.
