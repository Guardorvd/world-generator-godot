# Этап 4, продолжение: цель путешествия и её положение — 04.11.2026

Выбрана одна проблема за пределами генерации: **сохранение предполагало, что любую
цель можно восстановить по идентификатору места**. На карте уже существует другой
случай — произвольная метка, выбранная игроком для свободного исследования.

## Корень и цепочка последствий

`GameWorld.save_state` записывал только строку `goal`. У произвольных точек она
одинакова: `marker`. Координаты существовали в текущем HUD и не попадали в файл.
При загрузке `Hud.restore_goal` искал строку в каталоге мест и трасс; произвольной
точки там нет, поэтому цель молча исчезала.

Расширение каталога стартами трасс решало предыдущий частный случай, но не могло
вернуть координаты метки. Проблема находится на границе сохранения: адрес места
и положение произвольной точки требуют разных данных.

## Выбор решения

| Вариант | Оценка |
| --- | --- |
| Регистрировать метки как новые места мира | Ненужные ID, владение каталогом и жизненный цикл временных мест. |
| Сохранять весь словарь цели, включая `src` | Связывает файл прогресса с внутренним представлением мира; именованное место лучше получать из текущего каталога. |
| Дополнить существующий адрес координатами свободной метки | Выбрано: достаточно одного необязательного значения. |

`goal` остаётся строкой. Для произвольной метки добавляется необязательный
`goal_marker: Vector2` — координаты в клетках карты. У именованных целей этого
поля нет. Контейнер `WGS1` и номер формата 1 сохранены; прежние файлы остаются читаемыми.

Карта и загрузка используют одну функцию `Hud.marker_goal`. При восстановлении
метка создаётся непосредственно по координатам, остальные цели разрешаются через
существующий каталог. Пустая цель и старое `goal = "marker"` без координат очищаются
без выдуманного положения. Проверка сохранения отвергает неверный тип, NaN/INF
и координаты, ошибочно приложенные к другой цели.

Новых классов, менеджеров целей, каталогов и механизмов генерации не добавлено.
Посещения, знания игрока и шаги заданий этим проходом не перестраивались.
