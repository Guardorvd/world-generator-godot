# Выборочный перенос велосипеда на 14.9

База: `codex/patch-3.1-mountains`, `4d320cd`. Отдельная ветка: `codex/14.9-bike-backport`. Исходная стабильная ветка и `Water-Massive-Forest` не изменены.

## Состав

- `2d7681a`: торможение, общий запас сцепления, боковая инерция, реакции седока, звук скольжения и небольшая поправка камеры.
- `e613574`: модели велосипеда и седока, анимации педалирования/нагрузки/прыжка, приземление с учётом полной горизонтальной скорости.
- Из `f3110f6` только `bike_crash.gd` и его тест: ограничение вращения костей и общий подъём тела вместо независимого перемещения конечностей.
- Из `59b24df` только исключение `tools/control/runs/**/*.cs` из компиляции: оставшиеся локальные архивы иначе вызывают дубли C#-классов при возврате на 14.9.

Не перенесены изменения генерации, воды, лесов, гор, дорог, навигации, размещения велосипеда, теней и кэша. `scripts/world`, `scripts/core`, Heightfield, RegionStream, RoadNavigation и `project.godot` совпадают с базой. Модели и основные скрипты анимации совпадают с `e613574`; скрипт падения совпадает с `f3110f6`.

## Адаптация

Убраны зависимости BikeRide и нового теста от водной динамики 15.3: течение, водный снос и новые методы Heightfield. Сохранены ограничения прохода через воду из 14.9. В тесте приземления одна и та же мировая скорость теперь задаётся только продольной и боковой составляющими.

Новый полный шаг 120 Гц выявил регрессию: 8-сантиметровая ступенька создавала ложный импульс взлёта. Подъёмная скорость ограничена направленной производной поверхности на базе колёс. Ступенька снова сжимает переднюю, затем заднюю подвеску; проверки быстрого гребня и края проходят.

## Проверки

- `dotnet build --no-restore`: успешно, 0 предупреждений, 0 ошибок.
- Godot 4.7.2 .NET, headless import: успешно.
- `bike_traction_test.gd`: 0 ошибок, включая приземления, торможение, 30/120 Гц, контакты, 360 крайних поз и шесть режимов анимации. Предупреждение о HandL ожидаемо: тест намеренно повреждает скелет.
- `bike_crash_test.gd -- --flat --cases 0,3,9,13`: 0 ошибок; земля, ствол, склон, стена туннеля, восстановление и камера.
- `bike_handling_test.gd`: остаётся один сбой «трамплин на скорости — настоящий прыжок». Он воспроизводится и на оригинальных BikeRide/GameConfig и тесте из `4d320cd`; это не новый сбой переноса. Остальные проверки проходят, включая исправленную ступеньку.
- `git diff --check`: чисто. Изменения вне заявленного состава проверены по diff относительно базы и источников.

Логи: `tools/control/runs/14_9_backport_{traction,crash,handling,baseline,import}.log` (локальные, игнорируются Git). Сравнение с базой выполнялось без переключения игровой ветки, на копиях исходных скриптов в `tools/control/runs/backport_compare`.

Генерация большого мира, FPS и визуальная поездка не проверялись. Эта ветка подготовлена для отдельной игровой оценки; в стабильную ветку не объединена и на сервер не отправлена.
