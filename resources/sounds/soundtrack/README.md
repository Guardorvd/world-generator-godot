# Саундтрек

Сюда кладутся музыкальные треки игры: `.mp3`, `.ogg` или `.wav`. Список не нужен — игра сама находит все файлы в папке.

Как они звучат (scripts/audio/music_director.gd, числа — GameAudioConfig, группа «Music»):

- мир начинается тишиной с природой, первый трек приходит через 25–55 с;
- каждый трек плавно входит и плавно уходит; длинные треки уходят после ~5 минут, не доигрываясь;
- между треками 1,5–3,5 минуты тишины; порядок перемешан, повтор только после всех;
- на паузе музыка тише, но не обрывается;
- громкость — «Музыка» в настройках звука (по умолчанию 50 %); 100 % уже тише самих файлов (`db_music`).
